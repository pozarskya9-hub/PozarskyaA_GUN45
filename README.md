# Tank Project

Простейший тестовый проект на Unity.

## Что есть в проекте

Прототип симулятора танка с двумя уровнями для отработки управления и стрельбы.

## Возможности
Управление через компонент Test Input Controller:

W/A/S/D — движение и поворот;

E — стрельба;

Space — ручной тормоз (полная остановка).

Панель скорости — отображение текущей скорости танка (доступна на обоих уровнях).

Счётчик попаданий — учёт успешных выстрелов (активен на уровне 2).

## Уровни
«TemplateScene» — прямой участок для тренировки управления и контроля скорости.

«MainScene» — площадка с кубическими мишенями: после попадания мишень возрождается в случайном месте через 3 секунды.

Технические детали
Окружение: ровный пол, базовое освещение.

Физика: коллайдеры на всех объектах, инерция при движении.

Звуковое сопровождение: звуки двигателя, выстрела и взрывов.

## Прототип предназначен для:

тестирования механик управления танком в Unity;

демонстрации базовых возможностей Test Input Controller;

быстрой проверки игровых идей и прототипирования.
